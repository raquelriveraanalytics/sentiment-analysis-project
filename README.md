# Sentiment Analysis Project

This project performs sentiment analysis on Amazon product reviews using two approaches:

- Lexicon-based method (TextBlob)
- Machine learning models

Steps included:
- Text preprocessing (cleaning, tokenization, stopword removal)
- Sentiment classification
- Model evaluation using accuracy, precision, recall, and F1 score

Tools used:
- Python
- TextBlob
- Machine Learning models

This project demonstrates how natural language processing can be used to analyze customer opinions and support business decisions.
